## 1. Vision & Objectives

**Vision**  
Build the **fairest, most accessible PoW token** on Starknet — a 100% community-driven token where **real humans using browsers and phones** get the vast majority of the supply. Phase 1 focuses on pure mining + genesis sale to create immediate liquidity and development runway without any hidden team premine.

**Phase 1 Success Goals**
- Launch a fully functional, browser-first miner in < 4 weeks.
- Achieve wide distribution: thousands of unique real wallets mining daily.
- Raise $30k–$150k+ via transparent genesis sale to seed liquidity + fund development.
- Create a fun, addictive mining experience that feels like the original Ethereum HASH miner but **fairer**.
- Lay technical foundation for Phase 2 (dVPN hybrid with 40% yield boost + buyback/burn).

**Core Principles**
- Maximum fairness: phones & browsers matter most.
- Strong anti-Sybil / anti-bot / anti-GPU-farm mechanics baked into the contract.
- No team allocation, no VC tokens, no hidden premine.
- Transparent, on-chain everything.

## 3. Key Features — Phase 1 Scope (MVP)

### 3.1 Smart Contract (Cairo 2 / Starknet)
- Genesis Sale contract (fixed price, wallet cap, first-come-first-served)
- Mining contract with:
  - One active challenge per wallet (`current_challenge[address]`)
  - Hard daily mint cap (configurable, default **10 mints per 24h** per wallet)
  - Mint cooldown (5–10 minutes)
  - Challenge = `blake2s(wallet + epoch + latest_block_hash + BrotherID?)`
  - On-chain verification of BLAKE2s hash + nonce
  - Difficulty adjustment (Bitcoin-style retarget)
  - Epoch rotation + halving logic
  - Fingerprint storage (one-time per wallet)
  - Brother ID bonus (2× daily cap for verified Brother ID holders)
- `seedPool()` function to mint LP-side tokens and lock liquidity
- All admin functions time-locked + multisig (transparent dev fund)

**Algorithm:** BLAKE2s (native/fast on Starknet, excellent WASM performance, ASIC-resistant enough for early stage)

### 3.2 Browser Miner (Web + WASM)
- Single-page web app (React/Vite recommended)
- Multi-threaded WASM mining (parallel workers based on CPU cores)
- Real-time hashrate, ETA, progress bars, era info
- Automatic challenge fetching & submission via starknet.js / argent/x
- **Browser fingerprinting** (Canvas + WebGL + AudioContext + hardware concurrency + fonts + screen)
- Fingerprint submitted once and bound to wallet
- Clean UI exactly like the HASH miner screenshot you shared
- “STOP” button, tip slider (optional), keep-mining toggle
- PWA support for phone home-screen install + background mining (where possible)

### 3.3 Anti-Sybil & Fairness Mechanisms
| Mechanism                  | Enforcement     | Effect |
|---------------------------|-----------------|--------|
| One challenge per wallet  | On-chain        | Blocks multi-tab abuse |
| Daily mint cap (10)       | On-chain        | Caps GPU farms per wallet |
| Mint cooldown             | On-chain        | Prevents spam |
| Browser fingerprint       | Client + contract | Detects cloned browsers |
| Brother ID bonus          | On-chain        | Rewards real humans (2× cap) |
| Challenge freshness       | Latest block hash | Stops pre-computing |

### 3.4 Genesis Sale Flow
1. Users buy SBLAKE at fixed price with ETH/STRK
2. No per-wallet cap during genesis (first-come-first-served)
3. Sale ends at 1,050,000 tokens sold
4. Proceeds automatically used to seed DEX pool + lock LP forever

## 4. User Flows

**1. New User Mining Flow**
1. Visit miner.starkblake.xyz → Connect Starknet wallet
2. (Optional) Verify Brother ID for 2× daily cap
3. Click “START MINING” → get challenge + start WASM workers
4. Browser mines in background
5. On valid nonce → auto-submit tx → mint reward
6. Daily cap reached → friendly message “Come back tomorrow!”

**2. Genesis Buyer Flow**
1. Visit sale page
2. Buy SBLAKE with ETH/STRK
3. After sale ends → trade on DEX or start mining

**3. Monitoring Dashboard**
- Live stats: total minted, current difficulty, global hashrate estimate, era progress

## 5. Non-Functional Requirements

- **Performance:** > 100 MH/s on modern laptops, usable on mid-range phones
- **Gas:** All mints < 300k gas (Starknet advantage)
- **Security:** Contract audited (at least one reputable auditor before mainnet)
- **UX:** Works on mobile browsers, dark mode, mobile-optimized
- **Privacy:** No telemetry except optional anonymous stats
- **Decentralization:** No central server required after launch (challenges fetched directly from Starknet RPC)
- **Accessibility:** Open-source (MIT license)
